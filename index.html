wakepi backup

wakepi backup is a private, single-user tool. It runs on a home server (a Raspberry Pi) belonging to its owner and copies that server's own nightly backup to the owner's Google Drive. It is not offered to anyone else.

Privacy policy

What it accesses. The app requests only the drive.file permission. With it, Google lets the app see and change only the files the app created itself. It cannot see any other file in the Drive.

What it stores. Backup files of the owner's own home server, encrypted on the server before upload. Google only ever holds the encrypted data.

What it shares. Nothing. No data is sold, shared, sent to third parties or used for advertising or analytics.

How to revoke. Remove "wakepi backup" at myaccount.google.com → Security → Third-party connections. The app then has no access at all.

Contact. The owner, via the GitHub account that hosts this page.
